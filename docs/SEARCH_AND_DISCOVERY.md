# Search and discovery policy

Create useful original material for people. Never promise Google indexing, E-E-A-T ranking or forced referral traffic from AI Overviews. robots.txt governs crawl preferences and cannot guarantee deindexing; add temporary-host X-Robots-Tag/noindex for preview protection if a public search crawl matters. llms.txt is an optional discovery document, not an official Google ranking lever.

Use descriptive titles; truthful authorship, verified dates and primary source links; canonical URLs under confirmed domain; structured data only when page facts support it. No invented FAQ schema, ratings, author credentials or applicant outcomes. Favor original scholar interviews, application checklists, evidence-based comparisons and interactive tools that summaries cannot replace.
