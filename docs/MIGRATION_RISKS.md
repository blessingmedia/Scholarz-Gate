# Migration risks

- Premature canonical change loses historic traffic: maintain explicit old-to-new URL map before moving domains.
- Publishing on Workers preview host may create duplicate search records: disable crawling before final canonical domain.
- Blogger XML includes proprietary assets/scripts; require license confirmation to copy directly.
- Third-party media hosted on original site may disappear: obtain rights and migrate.
- Unverified student profiles expose privacy risks: consent and moderation before profiles.
- Agent-generated claims and editorial boilerplate can become scaled-content abuse: originality/evidence/human review gates mandatory.
- Model API keys must stay in GitHub/Cloudflare secrets; never copy into code or external scripts.
- Existing basic Google article is a migrated seed, not a verified production research workflow.
- D1/R2, email, comments and Python/Gemini adapters are not live; treat as blocking next-phase milestones.
